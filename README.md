# Sliding Puzzle Arena 🎭⚡

Game interaktif berbasis web yang memotong gambar wajah pengguna secara *real-time* menjadi kepingan puzzle acak, kemudian disusun kembali menggunakan **kontrol gestur tangan (AI Computer Vision via MediaPipe Hands)**. 

Terinspirasi dari konsep interaksi web modern, game ini mendukung mode bermain mandiri maupun balapan layar terpisah bersama teman.

## 🚀 Fitur Unggulan
- **AI-Powered Controls:** Tanpa mouse atau keyboard! Interaksi puzzle digerakkan murni lewat deteksi kamera dan kecerdasan artifisial pelacakan tangan.
- **Dual Game Modes:**
  - **Singleplayer:** Selesaikan tantangan puzzle wajahmu secepat mungkin melawan waktu (*Speed Run*).
  - **Multiplayer Split-Screen:** Balapan susun puzzle bersama teman di satu layar komputer menggunakan tangan kiri dan kanan secara bersamaan.
- **Responsive Dashboard UI:** Desain antarmuka bertema gelap (*cyberpunk-glow*) yang ringan dan estetik.

## 🛠️ Teknologi yang Digunakan
- **Front-End:** HTML5, CSS3 (Modern Flexbox/Grid), JavaScript (ES6+ Modules)
- **AI/Computer Vision:** [Google MediaPipe Hands](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker)
- **Deployment:** GitHub Pages / Vercel

## 🎮 Cara Bermain
1. Buka game melalui tautan live demo yang tersedia.
2. Pilih mode bermain: **Singleplayer** atau **Multiplayer**.
3. Izinkan akses kamera perangkat kamu.
4. Angkat tanganmu ke arah kamera untuk melakukan jepretan (*capture*) wajah.
5. Gunakan gestur jari tertentu (mengetuk/menempelkan ujung jari) untuk memilih dan menggeser potongan puzzle ke posisi yang benar!
